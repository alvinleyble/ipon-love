# v1.7.1 Release Notes

- Notification inbox: budget, recurring, and partner-debt alerts
- Floating calculator bubble
- Direct account balance adjustment
- Spread debt overpayments across other debts
- Optional off-app recurring reminders
- Recurring calendar tab (Premium)

## Full

- 🔔 New notification inbox — alerts for budget limits, upcoming recurring bills, and when your partner logs a new debt
- 🧮 Calculator is now a floating bubble you can drag anywhere and use without leaving your screen
- 💰 Adjust an account's balance directly, without creating a manual transaction
- 🤝 Overpaying a debt? Spread the extra amount across your other debts in one go
- ⏰ Optional off-app reminders for upcoming recurring bills, even when the app is closed
- 📅 Recurring now has its own Calendar view tab (Premium)
- 🎯 Widget tip card to help you discover the home-screen balance widget
- 🧹 Cleaner navigation: Records header decluttered, module tabs justified edge-to-edge, "Coming up" card can now be collapsed
- 👁️ Privacy eye (hide amounts) now works consistently across every screen, including Records
- 📖 Refreshed in-app tutorial to match all the recent changes
- 🐛 Fixed a bug where editing a debt-settlement transaction could break its settlement status
