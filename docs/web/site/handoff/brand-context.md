# Brand & Product Context — Love, Ipon

For writing marketing copy and deciding what to screenshot, without needing the full app repo. Excerpted from `ipon-love`'s `CLAUDE.md` and project memory, current as of 2026-07-31.

## What it is

A couples personal finance + notes Android app for the Philippine market. Users track individual expenses and share a combined financial view with their partner. Clean, aesthetic UI. Offline-first with cloud sync.

The developer's personal instance is branded **PattyWallet** — the founding couple is Alvin (accent blue) and Patty (accent pink). Useful as a north star for tone, not something to put on the public site.

## Core features (V1 — what to screenshot / highlight)

- **Budget tracker** — transactions, accounts, categories, budgets, spending analysis, recurring transactions
- **Notes** — rich text, checklists, images, optional partner sharing
- **Couples pairing** via invite code; combined view with color-coded attribution (blue/pink per partner)
- **Shared couple budgets** — per-category, counts both partners' combined spending
- **Partner Debt Tracker** — couples-only IOU tracking between partners
- **App lock** — PIN + biometric
- **Multiple themes** — light + dark + more
- **Home screen widgets** — balance widget + quick-add shortcut

## Navigation (for consistent terminology in copy)

Bottom nav tabs: Records | Analysis | Budgets | Accounts | Categories

## Monetization (for a pricing/CTA section, if the site has one)

**One-time ₱249 purchase for Premium** — not a subscription. Generous free tier: recording your own money is never gated. Premium sells higher caps, cosmetics (extra theme palettes), and delighters (calculator, recurring calendar, deep history).

## Currency

PHP only — don't imply multi-currency support.

## Don't advertise (explicitly not in the app — avoid overpromising)

AI chatbot, password vault, voice recording, iOS app (not on the roadmap yet), custom fonts, profile/couple photo upload.

## Current build status (don't overstate)

Still pre-launch / active development. Currently in Play Console **internal testing only** — there is no public listing yet. Copy should not imply general availability. See `links-and-refs.md`.
